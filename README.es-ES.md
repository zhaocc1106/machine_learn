## Inicio rápido
   Se recomienda utilizar PyCharm como IDE, y tratar cada directorio como un proyecto <br>
   Para el entorno de Python, se utiliza Anaconda, con la versión Anaconda3-5.1.0.<br>
   El proyecto NeuralNetworks-tensorflow requiere un entorno de TensorFlow. Para el proceso de instalación de tensorflow-gpu, se sugiere consultar el siguiente enlace del blog personal:
   https://blog.csdn.net/zcc450959507/article/details/89672332
